## Why

Escapement documents a compact three-section oracle for low-blast-radius work, but
the executable oracle gate still requires all nine full-brief headings and the
rapid molecule always dispatches an adversarial reviewer. The advertised rapid
path is therefore not executable as documented and adds assurance ceremony even
when risk is bounded.

## What Changes

- Make the oracle gate accept a semantically complete three-section rapid brief.
- Define fail-closed, observable exclusions that require the full brief and
  stronger assurance.
- Keep independent truth, binding constraints, discriminating controls,
  missing-data behavior, and observed outcome proof inside the compact form.
- Replace `mol-rapid`'s unconditional adversarial-review dispatch with conditional
  independent review triggered by protected surfaces, specialty or maturity gaps,
  or a named failure mechanism.
- Escalate the current run when protected scope or oracle uncertainty appears.
- Treat a branch, commit, or vertical slice as an early durable artifact and a PR
  as review-ready work rather than unfinished inventory.
- Preserve final user-facing outcome verification and the separate
  `oracle-independence` contract.

## Capabilities

### New Capabilities

- `rapid-delivery-path`: Risk-bounded rapid work can use a compact but
  semantically complete oracle, conditional independent review, leading
  escalation, and a review-ready PR boundary.

### Modified Capabilities

None.
